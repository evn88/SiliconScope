**🔌 Which network carries the traffic.** The Network section lists each interface
under the totals — Ethernet, Wi-Fi — with its own download and upload, the one
carrying the default route first. An interface needs a routable address to be
listed, so internal link-local-only interfaces stay out. The totals no longer count
VPN tunnels: a `utun` interface (Tailscale, WireGuard) carries the same bytes your
Wi-Fi or Ethernet already counts, so they were counted twice.
([#74](https://github.com/kennss/SiliconScope/pull/74), @ticlazau)

**💾 What your SSD has done.** The internal SSD's reads and writes since boot — from
the storage driver's own counters, so they include everything before SiliconScope
started — and over its lifetime. Its NVMe SMART readings, read-only: remaining
rated endurance, temperature, spare capacity, media errors, and each critical
warning by name rather than folded into a health score. On the dashboard's Disk
card and the SSD menu. ([#77](https://github.com/kennss/SiliconScope/pull/77),
@evn88)

Disk sampling also got cheaper on the way: one driver enumeration and one read per
tick serve both the activity rates and the new totals.

The Mac agent is now **1.4.1** for the network totals above; the Linux agent is
unchanged at 1.4.0.
